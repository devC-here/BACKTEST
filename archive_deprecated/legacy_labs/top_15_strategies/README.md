## 3. How to Import and Use in Another Working Folder

To use these strategies in another repository, project, or machine:
1. **Copy the entire `top_15_strategies` folder** to your new project location.
2. It has **zero dependencies** on external repository folders (all rules, parameter specs, and datasets are localized inside).
3. Query the isolated database `top_15_trades.db` directly using standard SQLite or Python:
   ```python
   import sqlite3
   import pandas as pd

   conn = sqlite3.connect("top_15_strategies/top_15_trades.db")
   df_v38 = pd.read_sql_query("SELECT * FROM v38_hours_optimized_trades", conn)
   print(f"Loaded {len(df_v38)} authentic trades. Total Net Pips: {df_v38['pnl_pips'].sum():.1f} p")
   conn.close()
   ```

## 4. How to Run Backtests

From inside the `top_15_strategies/` directory:

- **1-Click Launch**: Double-click `run_top_15_backtest.bat`.
- **Backtest All 15 Models (V38 Hours Filtered)**:
  ```bash
  python backtester.py --strategy all
  ```
- **Backtest All 15 Models (V37 24/7 Continuous)**:
  ```bash
  python backtester.py --strategy all --no-hours-filter
  ```
- **Backtest Single Model (e.g. S08 Smart Money)**:
  ```bash
  python backtester.py --strategy S08
  ```
- **Custom Spread Friction**:
  ```bash
  python backtester.py --strategy all --spread 1.2
  ```
- **Backtest on Custom Bar Data**:
  ```bash
  python backtester.py --csv path/to/your_bars.csv --out-csv custom_trades.csv
  ```
